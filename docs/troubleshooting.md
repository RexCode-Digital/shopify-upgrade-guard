# Troubleshooting

Use `--format json` to inspect inventory and classifications. If a version is missing, check that it is in a Shopify URL, Shopify TOML `api_version`, or recognized client configuration. Generated files and files over 1 MiB are intentionally skipped. Invalid target versions must use `YYYY-01`, `YYYY-04`, `YYYY-07`, or `YYYY-10`.
