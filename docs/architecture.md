# Architecture

Discovery produces bounded source files and a structured Shopify version inventory. Rules provide detection metadata and version-aware evaluation. The scan orchestrator combines the current tree, target version, configuration, baseline fingerprints, and optional independent base-tree analysis. Base worktrees disable Git filters and hooks, and scanner code only parses files; it never runs project scripts. Stable finding identities classify new, existing, and resolved findings across changed lines and recognized file renames. Output adapters render the result as human text, JSON, SARIF, or Action annotations.
