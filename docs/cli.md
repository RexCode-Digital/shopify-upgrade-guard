# CLI reference

`scan` accepts `--target`, `--path`, `--format`, `--fail-on`, `--fail-on-new`, `--base-ref`, and repeated `--exclude`. `baseline create` writes the current finding fingerprints; `baseline check` evaluates the current scan. `rules` lists bundled rules. `versions` lists bundled support metadata. `explain RULE-ID` prints evidence and migration guidance.
