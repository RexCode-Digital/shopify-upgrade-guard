# Contributing

Keep rules evidence-first: each Shopify-specific rule needs an official `shopify.dev` source, affected version or status, bounded detection logic, migration guidance, and a fixture test including false-positive coverage.

Run `npm test`, `npm run lint`, and `npm pack --dry-run` before submitting a change. Do not add dependencies without a strong reason. AI-assisted contributions must be reviewed and understood by the human submitter.

For quarterly updates, follow [the maintainer process](docs/maintainer-release-process.md). Do not report findings about third-party repositories publicly.
