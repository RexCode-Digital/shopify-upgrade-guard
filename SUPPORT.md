# Support

Use [GitHub Issues](https://github.com/RexCode-Digital/shopify-upgrade-guard/issues) for reproducible bugs, documentation problems, and focused feature requests. Include the Shopify Upgrade Guard version, command or Action configuration, Node.js/npm and operating system versions, a minimal sanitised reproduction, and expected and actual behaviour. For rule reports include the target API version and the smallest relevant source or configuration pattern.

Remove credentials, tokens, merchant/customer data, private source, private URLs, and production secrets. Do not post suspected vulnerabilities publicly; follow [SECURITY.md](SECURITY.md) for private reporting.
