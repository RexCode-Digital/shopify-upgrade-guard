# Roadmap

- Extend target-aware rules when official Shopify notes support reliable static detection.
- Expand high-confidence coverage where Customer Account, POS, Functions, and GraphQL changes can be identified statically.
- Revisit generated GraphQL deprecation metadata only if Shopify provides a versioned source with clear redistribution rights; see [the technical decision](docs/graphql-deprecation-metadata.md).
- Keep the established release workflow, npm provenance, and immutable Action references current.
